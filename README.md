# CS 300 – Data Structures and Algorithms Portfolio Reflection

### What was the problem you were solving in the projects for this course?

In this course, I worked on creating a program for ABC University that would help academic advisors access course information more easily. The program needed to load course information from a file, organize the courses in alphanumeric order, and display course details, including prerequisites. The main goal was to create a program that was organized, efficient, and easy to use.

### How did you approach the problem? Consider why data structures are important to understand.

I approached the problem by comparing different data structures, including vectors, hash tables, and binary search trees. Each one has its own advantages and disadvantages when it comes to storing, searching, and sorting information. Understanding these differences helped me decide which structure would work best for the program. I learned that choosing the right data structure can make a big difference in how efficiently a program runs.

### How did you overcome any roadblocks you encountered while going through the activities or project?

One of the challenges I ran into was making sure the program correctly loaded course information and handled errors in the file. I also had to make sure courses with invalid prerequisites were not included in the final data structure. To work through these issues, I reviewed my code, used pseudocode to organize my logic, and made corrections based on instructor feedback. Testing different situations also helped me better understand what needed to be fixed.

### How has your work on this project expanded your approach to designing software and developing programs?

These projects helped me understand how important planning is before starting to write code. In the past, I would focus more on getting the program to work, but now I think more about how the program is organized and how efficiently it runs. Comparing data structures and analyzing run-time performance helped me see how different design choices can affect the overall program.

### How has your work on this project evolved the way you write programs that are maintainable, readable, and adaptable?

This course helped me improve how I organize and write my code. I learned the importance of using clear variable names, comments, and separate functions to make programs easier to read and understand. I also learned that writing organized code makes it easier to troubleshoot problems and make changes later. Moving forward, I plan to continue using these practices to create programs that are easier to maintain and improve.
